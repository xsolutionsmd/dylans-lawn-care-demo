# Dylan production static source

This main/updates lineage serves the public static demo from `dist/`. Read README and `docs/DEPLOYMENT.md`, `docs/VALIDATION.md` and `docs/SEO.md` where present. The `dev` branch is a separate booking/admin application; do not merge that entire branch into this static release to share design tooling.

For new/substantial visual designs use the installed Stitch design skills after selecting and viewing Inspo references. Preserve actual approved business facts, authentic assets, stack, canonical domain and public indexing behavior. If Stitch is unavailable on another computer, report it and use a chosen reference-to-code fallback. Do not add fictional reviews or pretend the static demo has a booking or submission backend. Contact actions use real verified destinations.

Develop this static product from `updates` or a focused main-based branch. Start with `.\website.ps1 dev -NoOpen`, package with `.\website.ps1 build -NoOpen`, and verify with `.\website.ps1 check -NoOpen`. Read the README for per-clone ports/project names and available shell wrappers; do not collide with the dev booking installation. Inspect desktop/mobile and contact/navigation behavior without sending messages or calling anyone.

An authorized merge into main publishes and automatically deploys the Oracle static demo. Setup/design instructions alone do not authorize that release. Apply tooling-only changes independently to each source lineage. Keep .agents and captured references outside the allowlisted production image. Reticle is opt-in if available; normal browser checks remain required.
