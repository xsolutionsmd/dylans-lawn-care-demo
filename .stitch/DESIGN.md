# Design System: Dylan — Field & Form
Project: 10457520769386141937. Dev public website and booking interface.

## 1. Visual Theme & Atmosphere
A spacious garden journal for an approachable local lawn-care business. Real
photographs and clear next steps. Editorial hierarchy, restrained surfaces and
quiet movement. No invented client proof, luxury-estate positioning or SaaS cards.

## 2. Color Palette & Roles
- Warm paper #f5f3eb: page canvas.
- Pine #254b38: headings, text, actions and closing section.
- Deep pine #173729: gallery background.
- Pale chartreuse #dce8a4: dark-section accents and primary closing action.
- Gray green #62695c: secondary text on light backgrounds.
- Muted green #617850: large italic headline accents.
- Rule #d3d7c8: subtle dividers and field boundaries.

## 3. Typography Rules
Self-hosted Newsreader normal/italic for expressive headlines; DM Sans 400–600 for
body and controls. Use a balanced large display scale, with a distinct mobile
composition. Georgia and Segoe UI fallbacks. Font display swap; no external font
dependency at runtime. Precise, short uppercase labels; readable plain body copy.

## 4. Component Stylings
Mostly square image frames, pill actions, thin ruled services and native FAQ
details. Visible focus; labeled inputs; minimum 44px primary controls. Existing
booking states retain semantic labels and truthful request/confirmation language.
Motion uses transform/opacity, respects reduced motion, and can be paused.

## 5. Layout Principles
Centered max-width 1400px; symmetric side margins, 112px desktop section seams,
72px mobile seams. Split hero and services, asymmetric horizontal gallery,
centered quotation, practical three-step process, two-column FAQ. Mobile stacks
clearly, keeps phone/booking accessible, never hijacks vertical scrolling.
